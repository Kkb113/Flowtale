## Implementation references

- [MDN Web Locks API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Locks_API): same-origin exclusive coordination and release tied to the callback promise. The editor uses this to protect the existing shared browser journal; server revision checks remain required across devices.

- [Intercom installation and session shutdown](https://developers.intercom.com/installing-intercom/web/installation) and [JavaScript methods](https://developers.intercom.com/installing-intercom/web/methods): pass user data through configuration, update/boot deliberately and clear session state at logout.
- [Flyway supported databases](https://documentation.red-gate.com/fd/database-version-support-143754067.html): the local migration CLI is validated against the actual database versions.
- [DOMPurify threat model](https://github.com/cure53/DOMPurify/wiki/Security-Goals-%26-Threat-Model): HTML sanitization does not sanitize CSS or recursively sanitize srcdoc automatically. Fable adds explicit policies for those contexts; captured CSS/network privacy is still under review.
- [MDN iframe sandbox](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe): same-origin parent DOM access does not require allowing scripts inside captured frames. Real browser geometry/interaction verification remains mandatory.
- [OWASP SSRF prevention](https://cheatsheetseries.owasp.org/cheatsheets/Server_Side_Request_Forgery_Prevention_Cheat_Sheet.html): validate destinations and redirects, including resolved addresses.
- [Apache HttpClient DNS resolver](https://hc.apache.org/components/httpcomponents-client-5.2.x/5.2.3/httpclient5/apidocs/org/apache/hc/client5/http/class-use/DnsResolver.html): validate the addresses used for connections, not only a preliminary DNS lookup.
- [Alpine 3.23 FFmpeg package](https://pkgs.alpinelinux.org/package/v3.23/community/x86_64/ffmpeg): pinned runtime package 8.0.1-r1. Deployment distribution must retain corresponding license notices/source obligations; no new video export capability is implied.

- [SeaweedFS mini](https://github.com/seaweedfs/seaweedfs/wiki/Quick-Start-with-weed-mini): local S3 stores persistent metadata and object data in the configured volume; telemetry and unrelated UI/protocol surfaces are disabled.
- [ElasticMQ persistence](https://github.com/softwaremill/elasticmq#persisting-queues-and-messages-to-sql-database): H2 persistence retains queue payloads as well as configuration. The local image creates its data directory for the non-root service user; synchronous writes are enabled and startup verifies actual object/message round trips.
